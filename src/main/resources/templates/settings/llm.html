LLM 설정

메모 요약에 사용할 로컬 LLM 서버를 연결하세요.

미설정
LLM 런타임

LLM PC의 Tailscale IP(100.x.x.x)만 입력할 수 있어요. LLM PC가 집·학교 등 어느 네트워크에 있든 같은 방법으로 연결돼요. 연결 가이드 보기

보안을 위해 LLM 서버 PC의 로컬 IP만 입력할 수 있어요 — 10.x · 172.16~31.x · 192.168.x · Tailscale 100.64~127.x (IPv6 fd00::/8 포함)
localhost·127.0.0.1(루프백), 169.254.x(링크 로컬), 공인 IP, 도메인은 사용할 수 없어요.

Tailscale 연결 가이드

요약은 이 서비스의 서버가 LLM PC에 직접 요청해요. 가정·학교의 PC는 공유기 뒤의 사설 IP를 쓰기 때문에 밖에서 바로 접속할 수 없어, Tailscale로 서버와 LLM PC를 연결합니다.

  1. Tailscale 설치 LLM을 실행할 PC에 Tailscale을 설치하고 로그인하세요.
  2. LLM PC 공유 Tailscale 관리 페이지의 Machines에서 LLM PC의 ⋯ → Share를 눌러 서비스 운영자(admin@example.com)서비스 운영자에게 공유하세요. 운영자와 같은 Tailscale 계정으로 로그인했다면 건너뜁니다.
  3. LLM 서버 열기 · 인증 토큰 켜기 (필수) LM Studio는 Developer 탭에서 서버를 시작하고 Server Settings의 Serve on Local Network를 켠 뒤, 인증(API 토큰)을 켜고 만든 토큰을 API Key 칸에 입력하세요. 토큰이 없으면 내 LLM PC의 IP를 아는 다른 회원이 내 LLM을 쓸 수 있어요. Ollama는 자체 인증이 없어 LM Studio를 권장해요. (Ollama는 OLLAMA_HOST=0.0.0.0으로 실행)
  4. Tailscale IP 입력 LLM PC에서 tailscale ip -4를 실행하거나 Tailscale 앱 메뉴에서 100.x.x.x 주소를 확인해 입력하세요. LM Studio의 Reachable at 주소가 http://100.x.x.x:1234라면 그대로 붙여넣어도 돼요.
  5. 연결 테스트 후 저장 모델 목록을 불러와 선택한 뒤 저장하세요. 연결되지 않으면 LLM PC의 방화벽에서 포트(LM Studio 1234 · Ollama 11434) 인바운드 허용을 확인하세요. 저장하면 요약에 실패했던 메모를 자동으로 다시 요약합니다.
