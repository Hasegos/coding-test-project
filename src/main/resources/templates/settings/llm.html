LLM 설정

메모 요약에 사용할 로컬 LLM 서버를 연결하세요.

미설정
LLM 런타임

보안을 위해 LLM 서버 PC의 로컬 IP만 입력할 수 있어요 — 10.x · 172.16~31.x · 192.168.x · Tailscale 100.64~127.x (IPv6 fd00::/8 포함)
localhost·127.0.0.1(루프백), 169.254.x(링크 로컬), 공인 IP, 도메인은 사용할 수 없어요.

연결 방법

  1. LM Studio Developer 탭에서 서버를 시작하고 Server Settings의 Serve on Local Network를 켜세요. 화면의 Reachable at 주소(http://IP:1234)를 서버 IP 칸에 붙여넣으면 IP·포트가 자동으로 나뉩니다.
  2. Ollama 다른 PC에서 접속하려면 OLLAMA_HOST=0.0.0.0으로 실행하세요. 기본 포트는 11434입니다.
  3. 같은 PC에서 실행 중이라면 localhost 대신 그 PC의 사설 IP(ipconfig / ip addr로 확인한 192.168.x.x 등)를 입력하세요.
  4. Tailscale LLM 서버 PC에서 tailscale ip -4로 확인한 100.x.x.x 주소를 입력합니다.
  5. 연결 테스트로 모델 목록을 불러와 선택한 뒤 저장하세요. 저장하면 요약에 실패했던 메모를 자동으로 다시 요약합니다.
